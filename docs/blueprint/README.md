# Clinical Agent System Blueprint & Architecture

This directory contains the engineering design documents, system blueprints, failure-mode analysis, and execution roadmaps for the **Better Clinical Agent** framework.

# Core Documents

- **`system_blueprint.md`**: Technical specification detailing the 4-layer epistemic agent architecture (Router, Modality Specialists, Evidence Evaluator, Disagreement Controller).
- **`audit_and_roadmap.md`**: Comprehensive 16-week project audit and execution roadmap structured into Track A (MVP Build), Track B (Research Extension), and Track C (Governance).
- **`failure_mode_corrections.md`**: Analysis of 11 documented failure modes in medical multi-agent systems and architectural design remedies to prevent them.
- **`research_dossier.md`**: Epistemic hypothesis framing and benchmark criteria for evidence-reliable clinical coordination.
- **`concept_notes/`**: Preliminary proposals and theoretical concept notes:
  - `evidence_reliable_coordination_concept_note.md`
  - `conflict_preservation.md`
  - `doubted_proposal.md`
