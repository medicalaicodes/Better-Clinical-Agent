**What jumps out reading this as a whole table, not five separate ones:**

The **Memory** and **Governance/Safety Features** columns are the emptiest in the entire table — far emptier than Architecture or Evidence-Grounding. Almost every system has *some* answer for "how does it reason" or "how does it ground evidence," but the large majority have **no answer at all** for "how does it remember/improve" and **almost none** have a real answer for "how is this governed/auditable/accountable." The few systems that do address memory (skill-memory, dual-memory, HealthFlow) and the few that address governance (MedSentry, the Ethical-AI-Governance paper, the lifecycle paper) are **disjoint sets** — no single system in this table combines a learned/persistent memory architecture with a governance-native design. That intersection is empty, which is exactly the kind of finding you want to be able to say plainly in a gap-analysis section.
