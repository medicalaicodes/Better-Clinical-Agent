Agentic AI in Healthcare

The Data Ingestion Layer & MAS Ecosystems

A Comprehensive Survey of SOTA Implementations


Goal: Handling diverse clinical data types accurately and efficiently.

Phase 1: The Paradigm Shift

From Static Data Entry to Active Agentic Perception.

  • Old Paradigm: Software passively waits for clean CSV data. Fails on messy clinical notes.
  • New Paradigm: Agent actively searches, reads, and chunks unstructured realities.
  • The Perceptual Bottleneck: If an agent is blind to a data modality, its downstream reasoning is fundamentally flawed.

Phase 2: Textual & Structured Data

Building the patient's historical baseline.

  • Natural Language: Interpreting patient symptoms and multi-turn dialogues.
  • EHR Databases: Translating clinical intent into executable code (SQL/FHIR) to query structured tables without token overload.
  • Clinical Notes: Algorithmically extracting timestamps to reconstruct longitudinal timelines from 10+ years of messy, fragmented PDFs.

SOTA Architecture: EHRFlow

LLM-Driven Iterative Multi-Agent EHR Analysis

Bypasses token limits by executing data operations natively inside the hospital sandbox.

Phase 3: Visual & Spatial Data

Encoding pixels into functional embeddings.

  • 2D Global (X-Ray): Ingested all at once.
  • Gigapixel (Pathology WSI): Active exploration and "Patching".
  • 3D Volumetric (CT/MRI): Massive token constraints. Requires 3D Positional Encodings to capture cross-slice continuity.

SOTA Architecture: CPathAgent

Multi-Scale Navigation for Gigapixel Pathology

graph LR WSI[Gigapixel WSI] --> Thumbnail[32x Downsampled View] Thumbnail --> Supervisor[Supervisor: Identifies Hotspots] Supervisor --> Explorer1[Zoom 10x: Path Planning] Explorer1 --> Explorer2[Zoom 40x: Detailed Feature Extraction] Explorer2 --> Synthesis[Diagnostic Narrative]

Treats diagnosis as an active visual navigation problem, avoiding O(N²) Transformer memory crashes.

Phase 4: Time-Series & Dynamic Data

  • The Chaos: Irregular sampling and heterogeneous frequencies.
  • CT-RoPE: Continuous-Time Positional Encoding aligns messy timestamps.
  • Mixture-of-Experts: Routes fast signals (ECG) and slow signals (Lab trends) to distinct neural pathways to avoid catastrophic forgetting.

SOTA Architecture: Personal Health Agent

Wearables Data Analysis via Code Execution

flowchart TD Query[User: "Am I getting more fit?"] --> LLM[LLM Data Science Agent] LLM --> Plan[Formulates Analytical Plan] Plan --> Code[Generates Pandas/Scipy Code] Code --> Exec[Secure Local Execution on Wearable DB] Exec --> Report[Translates Stats into Natural Language]

Solves LLM numerical hallucination by offloading math to deterministic local Python interpreters.

Phase 4: Symbolic Genomics

  • Symbolic Abstraction: Mutations (e.g. KRAS, TP53) lack intrinsic meaning without external retrieval.
  • Long-Range Dependencies: A mutation affects genes 50k base-pairs away.
  • SOTA Models: Deep Signal Processing (Evo) and Bidirectional State Space Models (JanusDNA) process 1M+ base pairs efficiently.

SOTA Architecture: HEAL-KGGen

Knowledge Graph Orchestration for Biomarkers

graph TD Biomarker[KRAS Mutation] --> GP[General Practitioner Agent] GP --> Specialist[Genomics Specialist] Specialist --> KG[(Dynamic Knowledge Graph)] KG --> |Maps| Entity[Entity: KRAS] Entity --> Pathway[Pathway: MAPK] Pathway --> Disease[Disease: Colorectal Cancer] Disease --> LLM[LLM: Generates Explainable Hypothesis]

Prevents factual hallucination by forcing the LLM to traverse verified semantic subgraphs.

Phase 5: Knowledge Retrieval (RAG)

Grounding logic in verifiable, external medical evidence.

  • Joint Latent Space: Projecting Images ($I$) and Text ($T$) into the same multidimensional universe ($R^d$).
  • Contrastive Learning: Uses InfoNCE loss to pull correct pairs together and push mismatched pairs apart.
  • Cosine Similarity: When a new X-Ray is ingested, the system mathematically retrieves the top $K$ most similar historical cases.

Phase 6: Multi-Agent System (MAS) Ecosystems

The "God Model" is dead. Long live the Virtual Tumor Board.

graph TD Director[Cognitive Orchestrator] --> Vision[Vision Sub-Agent] Director --> DB[Database Sub-Agent] Director --> Gen[Genomics Sub-Agent] Vision --> RAG[(Retrieval/Grounding Library)] DB --> RAG Gen --> RAG Vision --> Board{Verification & Conflict Resolution} DB --> Board Gen --> Board Board --> Output[Unified Clinical Decision]

Conflict Resolution

What happens when modalities disagree?

  • Text: "X-ray is clear."
  • Vision: "98% Confidence: Consolidation."

SOTA Action: The Verification Layer demands Saliency Maps from the Vision Agent. If mathematically overwhelming, the Director overrides the Text, flagging human error.

Conclusion

  • Active Perception: The ingestion layer is dynamic, algorithm-heavy, and specifically tuned per modality.
  • MAS Architecture: Bypasses token limits and data scarcity by delegating tasks to highly specialized sub-agents.
  • Clinical Safety: Grounded in RAG, continuous verification, and local execution pipelines.
