# Internship Presentations & Slide Decks

This directory contains the slide decks, PDF exports, markdown transcripts, and interactive HTML presentations created throughout the internship research, organized in chronological presentation order.

# Chronological Presentation Series

| Phase / Folder | Presentation Title | Available Formats | Key Focus & Scope |
|---|---|---|---|
| **`1/`** | **The Clinical Circuit Blueprint (EHR)** | `.pptx`, `.pdf` | Clinical circuit concept, structured EHR data ingestion & reasoning. |
| **`2/`** | **Medical Agentic Ingestion Architectures** | `.pptx` | Architectural blueprints for multi-agent ingestion pipelines. |
| **`3/`** | **Omni-Modal Synthesis** | `.pptx` | Omni-modal agent synthesis & early fusion vs. late fusion paradigms. |
| **`4/`** | **Clinical AI Reality Check** | `.pptx` | Empirical evaluation of SOTA models & reality-check on clinical readiness. |
| **`5/`** | **MultiModal Clinical Agents Presentation** | `.pptx` | In-depth analysis of Category 1.1 (Multi-Modal Clinical Agents, 27 papers). |
| **`6/`** | **Agentic AI in Healthcare Deck** | `.pptx` | Comprehensive synthesis of agentic AI capabilities, gaps, and benchmark results. |
| **`misc/`** | **Supporting Materials & Transcripts** | `.pptx`, `.md`, `.html` | Motivation deck (`HERALD_motivation_deck.pptx`), full presentation transcript (`internship_presentation.md`), narrative defense notes (`presentation_narrative.md`), and web viewer (`presentation.html`). |

# How to View
- **PowerPoint & PDF Decks**: Open `.pptx` or `.pdf` files directly within folders `1/` through `6/`.
- **Interactive Slide Deck**: Open `misc/presentation.html` in any web browser.
- **Text Transcript**: Read `misc/internship_presentation.md` for a slide-by-slide markdown transcript.
