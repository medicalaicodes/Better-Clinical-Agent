# Research Literature Database (300+ Papers)

This directory contains the structured literature database compiled during the research survey on **AI Agents in Healthcare**.

# Database Files

- **`categorized_paper_catalog.xlsx`**: Excel catalog categorizing ~300+ papers across **20 clinical agent categories** (13 Doctor-Facing, 4 Patient-Facing, 3 Infrastructure). Includes publication years, venues, primary modalities, and research themes.
- **`[Papers by Category]_MAIN.txt`**: Annotated master reference document containing paper abstracts, taxonomy classifications, and key findings.
