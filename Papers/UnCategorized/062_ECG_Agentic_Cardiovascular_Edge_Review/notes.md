# Problem Statement
While LLMs have revolutionized text, integrating them with raw time-series data (like ECG waveforms) for continuous, real-time cardiovascular monitoring on wearable devices (Edge AI) remains a disjointed field.

# Key Contributions
1. Provides a comprehensive systematic review of the intersection between ECG Foundation Models (like ECG-BERT, 3kg) and Agentic LLMs.
2. Proposes a taxonomy for "Agentic Cardiovascular Intelligence".
3. Identifies the critical gap: Agents need to translate raw waveforms into discrete textual tokens to reason about them effectively on-device.
