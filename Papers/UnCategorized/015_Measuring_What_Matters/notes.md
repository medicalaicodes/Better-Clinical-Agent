# Measuring What Matters: Benchmarking Generative, Multimodal, and Agentic AI in Healthcare
**Authors:** Prasanna Desikan, Harshit Rajgarhia, Shivali Dalmia, Ananya Mantravadi (Centific)
**Year:** 2026 | **Venue:** ArXiv
**ArXiv/DOI:** https://arxiv.org/abs/2605.08445

# Problem Statement
Existing medical AI benchmarks focus on "narrow accuracy" and knowledge-based testing (like USMLE), which fails to measure clinical reliability, safety, or performance in high-stakes, real-world workflows. Model performance degrades significantly as systems take on agentic roles.

# Key Contributions
1. Proposes a structured evaluation framework and a clinician-validated taxonomy (5 core categories, 22 subcategories, 121 clinical tasks).
2. Introduces a Benchmark Suite of 37 evaluations covering these categories.
3. Defines a "Maturity Ladder" (document -> detect -> act) to assess AI capabilities.

# Methodology / Architecture
The framework shifts focus from simple performance metrics to "clinical trustworthiness", measuring robustness, uncertainty handling, and data contamination.
