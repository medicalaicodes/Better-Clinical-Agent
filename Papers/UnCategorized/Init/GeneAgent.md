# GeneAgent: self-verification language agent for gene-set analysis using domain databases

**Publication:** *Nature Methods*, Volume 22, pages 1677–1685 (2025).
**Authors:** Zhizheng Wang, Qiao Jin, Chih-Hsuan Wei, Shubo Tian, Po-Ting Lai, Qingqing Zhu, Chi-Ping Day, Christina Ross, Robert Leaman, Zhiyong Lu.
**DOI:** 10.1038/s41592-025-02748-6

# Key Features and Purpose
*   **Self-Verification Mechanism**: Addresses hallucination in LLMs. After generating an initial biological interpretation of a user-provided gene set, it automatically cross-references its conclusions against trusted biological databases (like NIH databases) to ensure accuracy.
*   **Interpretability**: Provides explanatory analyses of how individual genes contribute collectively to a specific biological function or pathway.
*   **Application**: Assists researchers in interpreting gene sets (Gene Set Analysis - GSA) by turning them into reliable hypotheses.
*   **Benchmark**: First AI agent of its kind in GSA research, establishing a new standard for performance and interpretation.
