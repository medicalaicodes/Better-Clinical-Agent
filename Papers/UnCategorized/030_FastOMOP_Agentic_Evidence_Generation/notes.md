# FastOMOP: A Foundational Architecture for Reliable Agentic Real-World Evidence Generation on OMOP CDM data
**Authors:** N/A
**Year:** 2026 | **Venue:** ArXiv
**ArXiv/DOI:** https://arxiv.org/abs/2604.24572

# Problem Statement
Agents attempting to extract Real-World Evidence (RWE) from large EHR databases struggle with complex, standardized schemas like OMOP CDM (Observational Medical Outcomes Partnership). Text-to-SQL approaches frequently hallucinate joins and misinterpret clinical concept IDs.

# Key Contributions
1. FastOMOP: An agentic architecture that replaces raw Text-to-SQL with an abstraction layer (Tool-calling API) tailored for the OMOP schema.
2. Prevents the LLM from writing raw SQL; instead, it uses specialized tools (e.g., `get_cohort`, `calculate_incidence_rate`).
3. Massively improves the reliability of population-scale observational studies generated by AI.

# Methodology / Architecture
The agent is provided with an API wrapper around the OMOP database. When asked to "find the prevalence of Type 2 Diabetes in patients on Metformin," the agent chains the API calls, retrieves the structured results, and synthesizes the RWE report.

# Limitations & Future Work
The API abstraction layer restricts the flexibility of the agent compared to raw SQL, making highly bespoke queries difficult to execute.

# Relevance to Our Survey
Highly relevant for **EHR Integration & Operational Tasks**. Shows that tool-calling abstraction solves the massive gap of Text-to-SQL hallucinations in standardized medical schemas. Modality: Structured EHR (OMOP).
